# Styly's Amazing Hackpad
A simple macropad with 6 keys and an encoder knob.

[Case](https://cad.onshape.com/documents/8048d40b3579348c7bd36c3a/w/5161b2085178a2fb4e87a650/e/c5ba20084d70dba86dff4a65?renderMode=0&uiState=693449ba5ff217189cd2ce8e)
## Fearures
- 6 Keys
- 6 Leds for transparent keycaps
- 1 Encoder

Everything fits together using 4 M3 Bolts and heatset inserts.
